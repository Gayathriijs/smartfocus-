# SmartFocus Workstation

SmartFocus Workstation is a privacy-first IoT smart study desk built with an ESP32 and low-cost sensors. It monitors posture distance, occupancy, ambient light, noise, temperature, and humidity, then provides real-time feedback through an OLED display and buzzer.

## Core Capabilities

- **Sensor Monitoring**: posture distance, occupancy, light, noise, temperature, and humidity.
- **Real-Time Feedback**: immediate guidance via onboard OLED and buzzer alerts.
- **Study Session Support**: session tracking with break reminders to encourage healthy study habits.
- **Explainable Focus Score**: a transparent score derived from measurable desk/environment signals.
- **Optional Web Dashboard**: can publish data for remote monitoring and analysis when enabled.

## Privacy-First Design

- Works locally on-device by default.
- Cloud/dashboard publishing is optional and can be disabled.
- Prioritizes user control over data collection and sharing.
